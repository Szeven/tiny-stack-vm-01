# tiny-stack-vm

A tiny stack virtual machine for make.fun's 32-bit stack ISA: wrapping arithmetic, 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their exact exit codes.

Run: `node main.ts` — reads every instance under `$MAKEFUN_INPUT_DIR` (default `/input`) and writes `stdout.bin` + `exit.txt` per instance under `$MAKEFUN_OUTPUT_DIR` (default `/output`).
